## cued task switching*

- **Whether preparation produces the task switch cost.** Compared: Switch cost after cue-only trials. Factors: task switch, cue-only trials. Motonori Yamaguchi (2025), doi:10.1007/s00426-025-02107-2
- **Binding of response-independent task rules to context features.** Compared: Task-switch costs on context-repeat versus context-change trials.. Factors: task switch vs repetition, context repetition vs change. Moritz Schiltenwolf (2024), doi:10.3758/s13423-024-02465-9
- **task-selection vs task-execution failures in task switching.** Compared: task-confusion vs response-confusion errors and their impact on n-2 repetition costs. Factors: error type, task sequence (n-2 repetition). Luca Moretti (2022), doi:10.1007/s00426-022-01708-5
- **Effect of preparing vs performing a task on later switch cost.** Compared: switch costs following cue-only vs completed trials. Factors: preceding trial type, task switch, event timing, event predictability. Rachel Swainson (2019), doi:10.1007/s00426-019-01254-7
- **Dynamic task preparation under task uncertainty.** Compared: behaviour when the prepared task shifts after a longer cue-target interval, by changing stimulus category or rule. Factors: switch expectancy, switch type (category or rule), cue-target interval. [opencogdata/chai-et-al-2023]
- **metacontrol trade-off between flexibility and persistence via top-down modulation.** Yu‐Chin Chiu (2025), doi:10.1525/collabra.130894
- **Inhibition of cued versus executed task sets.** Factors: cue-task compatibility, practice. Alexander Berger (2024), doi:10.1007/s00426-024-02013-z
- **Whether changes in control demand alone drive metacontrol.** Factors: control demand. Moon Sun Kang (2022), doi:10.3389/fpsyg.2022.1032304
